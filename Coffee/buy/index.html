☕ 手沖咖啡必備器材（合羽橋採買清單）

以下是「一次買齊、CP 高、入門友善」的建議器材清單：

1. 濾杯（Dripper）
推薦：HARIO V60（01/02 號皆可）或 Kalita Wave。
入門 CP 高：HARIO V60 塑膠款（便宜、耐摔、熱不易散）。

2. 濾紙
一定要買與濾杯尺寸同系列（V60 → 錐形、Kalita → 扇形）。

3. 下壺（Server）
最通用：HARIO 600ml 耐熱玻璃壺。

4. 手沖細口壺（Kettle）
必要理由：穩定水流、控制萃取。
高 CP：TIMEMORE（泰摩）鵝頸壺。

5. 電子秤（Scale）
要求：0.1g 精度、可計時。
高 CP：TIMEMORE Black Mirror Nano / Basic+。

6. 手磨豆機（Grinder）
必要理由：新鮮研磨「比器材還重要」。
高 CP：1Zpresso JX-Pro 或 TIMEMORE C3。

7. 聰明杯（Clever Dripper / 浸漬式濾杯）
狀況：合羽橋 Union「可能有、但不保證」；建議入店直接問「Immersion Dripper」。
高 CP／必買度：⭐ 非常推薦新手入門，不太需要水流技巧。

8. 保溫壺（選購）
出門帶咖啡 or 多杯量必備。

📝 手沖咖啡步驟（新手照做即可）

步驟 1：磨豆
建議粉水比：1 : 15～1 : 16。
例如：15g 咖啡豆 → 注水 225g。

步驟 2：悶蒸
水溫：88～92°C。
時間：30–45 秒（你記得的口訣沒錯！）
注入咖啡粉量的 2 倍水（例：15g → 倒 30g 水）。

步驟 3：正式注水
目標總水量：例如 15g → 225g。
分段：2～3 次注水皆可。
水流：穩定、小圓繞圈。

步驟 4：萃取時間
全流程約：2:00 ～ 3:00。
太快 → 粉太粗；太慢 → 粉太細。

步驟 5：完成
輕搖 server 讓液體融合 → 倒入杯中即可。

🎯 聰明杯（Clever Dripper）沖法（更簡單）

1. 加粉（15g）

2. 直接注滿熱水（225g）

3. 浸泡 2:00～3:00

4. 放上下壺 → 自動開始滴濾

→ 完成！風味穩定、酸苦均衡、最適合新手。
