# Google Sheet 新增站點寫入設定

## 已完成的試算表準備

目標試算表「2026 東京冬日紀行 - 功課表網格版行程表」已新增分頁 **網站新增站點**，欄位為：

`ID｜日期｜時間｜景點名稱｜備註｜地圖連結｜新增時間｜狀態`

網站新增內容會進入這個收件分頁，狀態為「待併入行程」。這樣不會改寫既有 14 日主行程網格。主行程確認後，再由你手動併入原表。

## 一次性部署（約 5 分鐘）

1. 開啟[行程 Google Sheet](https://docs.google.com/spreadsheets/d/156UgwNFMgtzfKZjPQSCtm1svb6Mk6LTPNtOwE0EI0Gw/edit)，確認已看到「網站新增站點」分頁。
2. 在試算表選 **擴充功能 → Apps Script**。將這個檔案 [Code.gs](./Code.gs) 的完整內容貼進編輯器，儲存專案。
3. 在 Apps Script 編輯器選取函式 **setupWriteKey**，按「執行」並完成 Google 授權。打開執行記錄，複製輸出的長密碼；只複製給需要新增行程的家人，請勿貼進 GitHub 或公開訊息。
4. 選 **部署 → 新增部署作業 → 網頁應用程式**：
   - 執行身分：**我**
   - 存取權：若有 **任何人**，選它；若帳戶只允許登入使用者，選 **任何 Google 帳戶**。
   - 按「部署」並完成授權。複製結尾為 `/exec` 的網址。
5. 開啟[東京旅遊頁](https://travel.itigre.com/2026/tokyo/)，展開「備份與資料設定」，貼上網頁應用程式網址與剛才複製的密碼，按「套用本分頁設定」。
6. 用「+ 加一站」新增一筆測試資料。旅遊頁會保留本機版本，並在新分頁顯示寫入結果；回到 Sheet 的「網站新增站點」確認資料列與「待併入行程」狀態。

## 使用與安全

- 網址會存於此瀏覽器；密碼只存於目前分頁工作階段，關閉分頁後需重新輸入。
- 寫入服務只接受有效的旅程日期與欄位長度，並用 ID 防止同一筆重複寫入；不提供 Sheet 內容讀取。
- 網頁程式碼與部署網址不含密碼。任何拿到密碼的人都能新增資料，請只分享給可信任家人；若懷疑外洩，在 Apps Script 再執行一次 `setupWriteKey` 產生新密碼，並重新貼到旅遊頁設定。
- 寫入收件分頁不會自動更動主行程，也不會同步到其他家人的網頁本機清單；它是供全家查看、再決定是否併入主行程的雲端收件匣。
- 初次部署後才可做真實寫入測試；尚未部署前，旅遊頁的新站仍只保存在本機。

若 Apps Script 部署選項被 Google Workspace 管理員停用，請用個人 Google 帳號建立並部署這個 Apps Script，試算表仍由該帳號授權存取。
