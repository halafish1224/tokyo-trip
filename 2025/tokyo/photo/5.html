東京行程拍攝攻略（含構圖示意 + 白平衡技術）

器材 & 拍攝重點

旅拍以 Sigma 16-300mm（萬用）與 RF 50mm f/1.8（人像/夜拍）為主。

  • Sigma 16-300mm：景觀、壓縮感、街拍紀錄
  • RF 50mm f/1.8：人像、夜景散景、食物特寫
  • 單人以景觀為主；與家人同行補抓人物表情
  • 建議攜帶小腳架（夜景、日落）
  • 若想簡化裝備，16–300mm 一鏡走天下也可

逐日拍攝精華（含構圖示意）

點擊每一行展開詳細提示與示意圖，方便邊走邊查。

  • 室內與飯店周遭夜景：50mm f/1.8，ISO 1600–2500。
  • 若要低光更穩：開 手持夜景 模式。
  • 豪德寺貓群：50mm（近拍）與 300mm（壓縮堆疊）。
  • 市集：使用 靜音快門，追焦切換到區域AF。
  • 寺廟用中長焦呈現建築層次；遇逆光用 高光色調優先。
  • 日落：優先側光或逆光剪影，快門 1/200 以上視風強調整。
  • 合羽橋美食：用 50mm 拍食物特寫（食物模式可試）。
  • 羽子板市：人潮多以 70–200mm 或 16–300mm 中長焦防擾拍攝。
  • 神樂坂小巷：50mm 捕捉溫柔巷弄與人物互動。
  • 表參道建築：16mm 抓建築線條與聖誕裝飾。
  • 重點使用 50mm f/1.8，製造燈球散景與前景模糊。
  • 若有行人合影：側光 + 背景留燈球，構圖預留人物頭頂空間。

Canon R7 建議設定（旅拍精簡）

快速套用，方便出門在外調整。

  • 手持夜景：夜市與聖誕市集首選
  • 臉部 + 眼部追蹤 AF：家庭合照穩定
  • 靜音快門：寺廟・市場拍攝
  • 高光色調優先 (D+)：保留天空細節
  • 合照模式：多人時自動加深景深
  • Auto ISO 上限：建議設 ISO 3200

白平衡技術（C1 / C2 / C3）

根據情境給出最實用的 WB 模式、K 值與切換建議，並附 Canon R7 選單路徑。

C1 — 景觀 / 建築（日間）

首選： 日光（Daylight）（約 5200K）

替代： 陰影（Shade） → 想要較暖的畫面；或 自訂 K 5200–5800K（偏暖的膠片感）。

何時切換： 陰天、樹蔭、建築反射強時改用 陰影；想保留夕陽色溫時用自訂 K（5500–5800K）。

Canon R7 路徑： Menu → 拍攝2 → 白平衡 → 日光 / 陰影 / 自訂(K)

進階技巧：對同一國家地標拍三張（Daylight / Shade / 5500K），回飯店比對學習。

C2 — 人像 / 家人（白天 & 室內）

首選： 自動（AWB）— 氣氛優先（Canon 偏暖，膚色友善）

替代： 日光（逆光或窗邊側光）或 鎢絲燈（Tungsten）（室內黃光想修正時）。

何時切換： 室內強黃光、居酒屋、咖啡廳等改鎢絲燈；戶外逆光用日光保留金色。

Canon R7 路徑： Menu → 拍攝2 → 白平衡 → 自動 → 子選項（選「氣氛優先」）

進階技巧：拍人時先試 AWB（氣氛）→ 若臉偏色再切到「日光」或手動 Kelvin 微調。

C3 — 夜景 / 聖誕市集（弱光）

首選： 鎢絲燈（Tungsten）（把燈光顏色調冷，產生乾淨的夜間氛圍）

替代： Auto（AWB—白優先）（場景光色複雜時）；或 手動 K 2800–3200K（電影感/冷暖調整）。

何時切換： 想要暖冬感用 3200K；想要冷色電影感用 2800K；複合光源場景使用 AWB（白優先）。

Canon R7 路徑： Menu → 拍攝2 → 白平衡 → 鎢絲燈 / 自訂 (K)

進階技巧：夜市拍攝可試 3200K / 3000K / 2800K 各拍一張，回看哪一個最有氛圍再採用。

快速懶人表：C1（日光 / 5200K）、C2（AWB 氣氛優先）、C3（鎢絲燈 / 2800–3200K）。

攝影大師心法（旅行版）

簡短但高命中率的構圖與光線技巧 + 進階練習。

  • 風景 = 廣角 + 一個人物背影 → 立即有人文感
  • 夜景人像：用 側光 或 背光，避免正面路燈直射
  • 日落與海邊：試試 逆光剪影，構圖留負空間
  • 街拍：拍 30° 斜角，層次與深度較佳
  • 家庭照三構圖：背影、地標小人、餐桌自然互動

進階練習（養成技能計畫）

  • 每天 10 張練習題： 用同一地點拍 10 張，列出最佳 2 張並分析光線與構圖差異（寫下判斷）。
  • 白平衡實驗： 在同一場景拍 Daylight / AWB / 3200K（夜景）各一組，回飯店比較色溫差異。
  • 快門控制練習： 拍走路人用 1/125、1/60、1/30，觀察動態感差異並記錄參數。
  • 每週 1 次作品挑戰： 選 1 張作品，裁切、調色、寫下你調整的三項原因（主題、曝光、色彩）。

常見錯誤與避免方法

  • 錯誤：拍人時臉被街燈直射 → 解法：改側光或稍退距離，改為側光拍攝。
  • 錯誤：夜景用 AWB 導致黃到爆 → 解法：鎢絲燈或手動 3000K 減少黃污
  • 錯誤：天空過曝沒細節 → 解法：開 高光色調優先 D+ 或使用 AEB/HDR。
